# Privacy Policy

Last updated: 2026-02-15

This extension does not collect, transmit, or store any personal data off your device.

- No data is sent to external servers or third parties.
- No analytics, telemetry, or tracking services are used.

All user-configurable data (including your custom mantras and blacklist) is stored locally on your device using the browser's local extension storage. Specifically, data is kept in the extension's local storage area (for example `chrome.storage.local`) and never leaves your device unless you explicitly export or share it yourself.

The extension uses local content scripts and bundled resources to display the blocking overlay; these resources are included in the extension package and are not fetched from remote servers.

Permissions: the extension requests only the permissions it requires to function on your device. If you have questions about a specific permission, please check the source code or open an issue in the repository.

If you have concerns or want additional privacy guarantees, please contact the project maintainers via the repository where you obtained this extension.
